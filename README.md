# London Data Science Job Market Analysis

## 📌 Project Overview
This is an Exploratory Data Analysis (EDA) project using Python and Pandas. The goal was to analyze a dataset of job postings to understand the current demand and required skills for Data Science roles in London, UK.

## 🔍 Key Insights
After cleaning and analyzing a dataset of **205 job postings**, the following insights were found:
- **Python is king:** 87.8% of the job descriptions mention Python (180 jobs).
- **SQL is essential:** 54.1% of the descriptions mention SQL (111 jobs).
- **Top Hiring Companies/Agencies:** Datatech Analytics (13 jobs), Harnham (11 jobs), and GCS Recruitment Specialists (11 jobs).
